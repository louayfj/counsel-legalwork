# Vulnerable-Customer Flagging

Use this to identify vulnerability indicators in UK automotive retail interactions
and propose proportionate support actions.

## Required grounding

1. Search the active organisation's authorised reference material for `vulnerable customer`, `Consumer Duty
   support`, `PRIN 2A vulnerable`, and any product-specific issue.
2. Cite source rules/guidance and exact conversation/document evidence.
3. Call `compliance_citation_log` before final.

## Workflow

1. Review only the supplied interaction records unless the user asks you to search more.
2. Flag indicators, not diagnoses. Do not infer medical, financial, or personal
   status beyond the evidence.
3. Classify each flag as `explicit`, `implicit`, or `uncertain`.
4. Link each flag to a recommended support action and owner.
5. Escalate urgent harm, safeguarding, affordability, coercion, or complaint risk.

## Output

Produce a table:

Indicator, Evidence quote/location, Why it matters, Suggested support, Severity,
Citation.

End with:

- Immediate actions.
- Follow-up questions for the customer/dealer.
- Human-review/escalation recommendation.
- Data-minimisation note for sensitive personal data.
