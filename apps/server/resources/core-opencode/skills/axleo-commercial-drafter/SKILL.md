# Commercial Drafter

Use this to draft practical organisation legal/commercial wording after checking the
relevant context and sources.

## Required grounding

1. Search the active organisation's authorised reference folder for existing approved
   wording, templates, and prior positions before drafting.
2. For legal/regulatory claims, use authoritative sources and cite them.
3. Call `compliance_citation_log` before the final answer when the draft relies on
   legal or compliance claims.

## Workflow

1. Identify audience: client, prospect, supplier, internal team, board/founders,
   dealership, regulator, or solicitor.
2. Identify purpose: explain, negotiate, approve, reject, request information,
   document risk, or send final wording.
3. Draft in plain English with the active organisation's professional tone.
4. Separate final-ready wording from internal notes.
5. Include approval status: draft only, suitable for internal review, suitable
   for client review, or solicitor review required.

## Output

Return:

- Draft wording.
- Internal rationale and risk notes.
- Source/citation list.
- Approval checklist before sending.
- Suggested Word/PDF artifact name when a document should be created.
